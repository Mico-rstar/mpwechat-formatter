# 排版规则文档

本文档提供详细的排版规则，指导如何优化 Markdown 结构，使文章更易读。

## 标题规范化规则

### 层级限制

**原则**：不超过 3 层标题（h1, h2, h3）。

**原因**：
- 微信公众号文章通常不需要深层嵌套
- 过多层级会使文章复杂化
- 移动端阅读体验更好

**标题用途**：
- **h1**：文章主标题（仅 1 个）
- **h2**：主要章节（3-6 个）
- **h3**：子章节（可选）

### 标题结构

**推荐结构**：
```
# 文章标题

## 章节 1

内容...

## 章节 2

内容...

### 子章节 2.1

内容...

## 章节 3

内容...
```

**不推荐的结构**（超过 3 层）：
```
# 文章标题

## 章节

### 子章节

#### 再子章节  ❌ 超过 3 层
```

### 标题内容规范

1. **简洁明了**：标题不超过 20 字
2. **描述性**：标题应准确反映内容
3. **避免编号**：如"第一章"、"1.1"（Markdown 已有层级）
4. **每节内容**：每个标题下应有 1-3 段内容

### 标题转换规则

如果用户使用超过 3 层标题，进行以下转换：

- **h4 → h3**：降级到 h3
- **h5 → h3**：降级到 h3
- **h6 → h3**：降级到 h3

**示例**：

**原始**：
```
# AI 改变教育

## 个性化学习

### 自适应算法

#### 神经网络方法  ❌ h4
```

**优化后**：
```
# AI 改变教育

## 个性化学习

### 自适应算法与神经网络方法  ✅ 合并为 h3
```

## 列表优化规则

### 单项列表转段落

**规则**：如果某列表只有 1 项，改为段落。

**原因**：单项列表没有"列举"的效果，段落更自然。

**示例**：

**原始**：
```
AI 改变教育：
- 个性化学习
```

**优化后**：
```
AI 改变教育的关键是个性化学习。
```

### 多项列表保持

**规则**：2 项及以上的列表保持列表格式。

**示例**：

**原始**（保持不变）：
```
AI 改变教育的三个方面：
- 个性化学习
- 效率提升
- 公平性改善
```

### 嵌套限制

**规则**：最多 2 层嵌套。

**示例**：

**允许**（2 层）：
```
- AI 改变教育
  - 个性化学习
  - 效率提升
- AI 改变医疗
  - 辅助诊断
  - 药物研发
```

**不允许**（3 层，需要优化）：
```
- AI 改变教育
  - 个性化学习
    - 自适应算法  ❌ 超过 2 层
```

**优化方式**：将深层内容移到段落中。

**优化后**：
```
- AI 改变教育
  - 个性化学习（如自适应算法）

在个性化学习中，自适应算法能够根据学生的进度调整内容。
```

### 列表长度控制

**规则**：每项不超过 3 行。

**原因**：过长的列表项难以阅读。

**示例**：

**原始**：
```
- AI 改变教育的方式是通过个性化学习算法，这些算法能够分析学生的学习行为数据，然后提供定制化的学习内容和路径。 ❌ 超过 3 行
```

**优化后**：
```
- AI 改变教育的方式是通过个性化学习算法。

这些算法能够分析学生的学习行为数据，然后提供定制化的学习内容和路径。
```

## 间距规则

### 段落间距

**规则**：每 300-500 字添加一个空行。

**原因**：改善可读性，避免大段文字。

**计算方式**：
- 累计字数（不包括空格和标点）
- 达到 300-500 字时，添加空行
- 重新计数

**示例**：

```
（前 300 字）

（空行）

（继续 300 字）
```

### 标题间距

**规则**：标题前后留空行。

**示例**：

```
（上一段内容）

## 新章节

（章节内容）
```

### 长段落拆分

**规则**：长段落（> 150 字）考虑拆分。

**拆分方式**：
1. 按逻辑分句
2. 按主题分点
3. 使用列表

**示例**：

**原始**（200 字）：
```
人工智能正在深刻改变教育行业。通过个性化学习算法，AI能够根据每个学生的学习进度和特点，提供定制化的学习内容和路径。这不仅提高了学习效率，也让教育更加公平和可及。此外，AI还可以帮助教师自动化批改作业和分析学生表现，从而将更多时间投入到教学本身。
```

**优化后**：
```
人工智能正在深刻改变教育行业。通过个性化学习算法，AI能够根据每个学生的学习进度和特点，提供定制化的学习内容和路径。这不仅提高了学习效率，也让教育更加公平和可及。

此外，AI还可以帮助教师自动化批改作业和分析学生表现，从而将更多时间投入到教学本身。
```

## 其他排版规则

### 强调使用

**规则**：适度使用强调（加粗、斜体）。

**推荐**：
- 每段不超过 3 处强调
- 强调关键词和核心观点
- 避免整句强调

**示例**：

**好的强调**：
```
人工智能正在**深刻**改变教育行业。通过**个性化学习**算法，AI能够提供**定制化**的学习内容。
```

**坏的强调**：
```
**人工智能正在深刻改变教育行业。通过个性化学习算法，AI能够提供定制化的学习内容。** ❌ 整句强调
```

### 引用使用

**规则**：引用用于重要观点或引用他人言论。

**示例**：
```
> 个性化学习是教育的未来。
```

### 代码块使用

**规则**：代码块用于技术示例，使用 markdown 的语法。

**示例**：
````markdown
```python
def hello():
    print("Hello, World!")
```
````

## 排版优化清单

在优化 Markdown 结构时，检查以下项目：

- [ ] 标题不超过 3 层？
- [ ] 单项列表改为段落？
- [ ] 列表嵌套不超过 2 层？
- [ ] 每 300-500 字有间距？
- [ ] 标题前后有空行？
- [ ] 长段落（> 150 字）考虑拆分？
- [ ] 强调使用适度（每段不超过 3 处）？

## 常见问题

### Q1: 用户使用了 h4-h6，如何处理？

A: 降级到 h3。如果内容确实需要分层，考虑重新组织为多个独立章节。

### Q2: 列表嵌套太深，如何优化？

A: 将深层内容移到段落中，或使用多个独立的 2 层列表。

### Q3: 用户文档没有标题，如何处理？

A: 根据内容主题添加标题。如果不确定如何分章节，询问用户。

### Q4: 间距规则是强制的吗？

A: 不是硬性规则，而是指导原则。根据内容灵活调整，目标是改善可读性。

### Q5: 用户要求保持原有结构，怎么办？

A: 尊重用户要求，但可以建议优化。如果结构确实影响可读性，说明问题并询问是否可以优化。
